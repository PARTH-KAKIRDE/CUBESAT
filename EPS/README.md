# EPS — Electrical Power System

Power management module for the 2U CubeSat.

## Overview
Handles solar power generation, battery charging, and regulated power distribution to all subsystems (OBC, COMMS, ADCS, Payload).

## Contents
- `CubeSat_EPS/` — KiCad project (schematic + PCB + fabrication PDF)
  - `CubeSat_EPS.kicad_sch` — Schematic
  - `CubeSat_EPS.kicad_pcb` — PCB layout
  - `CubeSat_EPS.kicad_pro` — Project configuration
  - `CubeSat_EPS.pdf` — Schematic PDF export

## Tool
Designed in KiCad 7/8. Open `CubeSat_EPS.kicad_pro` to view the full project.
